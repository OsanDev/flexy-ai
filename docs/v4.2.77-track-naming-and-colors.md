# FLEXY AI v4.2.77: Track naming and color labels

- Video, audio, and caption tracks can be renamed inline, up to 32 characters.
- Each track can be assigned a Violet, Mint, Amber, Rose, or Blue organizational accent.
- Track names and color labels live in the timeline document and therefore follow the existing project save and undo/redo behavior.
- These are organizational labels only; they do not alter clip pixels, audio, or the render graph.
