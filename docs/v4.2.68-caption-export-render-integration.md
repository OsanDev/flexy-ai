# FLEXY AI v4.2.68: Caption Export & Rendering Integration

## What changed
- Caption styling now travels through the validated render graph instead of being discarded by the backend.
- FFmpeg subtitle rendering now uses generated ASS subtitles with per-caption font size, text color, bold weight, alignment, top/bottom placement, vertical offset, outline, shadow, and background box styling.
- Multiline captions retain intentional line breaks in the export.
- Caption colors, numeric ranges, alignment, and position are validated before rendering.
- Caption text is escaped before being written to ASS event content.

## Current limitations
- Caption animation presets (word reveal, karaoke, pop, fade, and slide) remain preview/editor behavior and are not animated in the exported file yet. Exports render each caption as a timed static subtitle.
- ASS subtitle rendering requires an FFmpeg build with the `subtitles` filter (libass support).
- Background box styling and text outline are constrained by ASS style capabilities; exact pixel parity with browser preview is not guaranteed.

## Validation
- Contract tests cover normalized style data, invalid style rejection, ASS color conversion, multiline text, positioning, escaping, and render-pipeline wiring.
