# FLEXY AI v4.2.71: 120 FPS Export

## Added
- 2K QHD export preset at 2560 × 1440 (portrait projects export at 1440 × 2560).
- 120 FPS selection for 1080p, 2K and 4K export presets.
- Increased target bitrates for 120 FPS preset exports: 1080p 18 Mbps, 2K 36 Mbps, 4K 52 Mbps.
- Preflight warning explains that genuine 120 FPS motion requires 120 FPS source footage; lower-rate sources are frame-rate converted.

## Notes
120 FPS is now accepted by render validation and passed to FFmpeg. Actual throughput depends on source frame rate, FFmpeg build, CPU/GPU, memory, storage and deployment limits. This release does not guarantee real-time rendering or motion interpolation.
