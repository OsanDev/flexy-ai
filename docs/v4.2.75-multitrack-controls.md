# FLEXY AI v4.2.75: Multi-track controls

## Track locking
Video, audio, and caption tracks can be locked independently. Locked tracks keep clip selection available but disable clip dragging, trimming, splitting, and removal from the track lane.

## Audio mute
Audio tracks include mute/unmute. Muting sets that track's clip volumes to zero in the timeline document and therefore in the generated render graph. Unmuting restores the exact per-clip volume values captured when the track was muted.

## Scope
Track lock state is editor-session state. Audio mute is part of the timeline document and follows normal document updates/undo behavior. This release does not add track visibility or solo.
