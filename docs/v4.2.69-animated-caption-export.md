# FLEXY AI v4.2.69: Animated Caption Export

## What changed
- The render graph now validates and carries caption animation type and duration.
- Word reveal exports progressive timed subtitle events, matching the preview's reveal window and holding the completed line until the caption ends.
- Karaoke exports per-word timed ASS karaoke tags with a gold active-word highlight. Timing is evenly distributed because the current editor stores caption-level timing, not word-level transcript timestamps.
- Pop exports an ASS scale transform, fade exports an ASS fade-in, and slide exports an ASS vertical move.
- Existing caption typography, alignment, position, outline, shadow, background, and multiline text remain integrated with the animation output.

## Current limitations
- Word and karaoke timing is evenly distributed across words. It is not phoneme- or speech-aligned.
- Pop/fade/slide are entrance effects. There are no exit effects or keyframe editor yet.
- ASS animation rendering requires FFmpeg's `subtitles` filter with libass support.
- Browser preview and FFmpeg output may differ slightly in font metrics and animation interpolation.

## Validation
- Contract tests cover animation validation, word reveal timing, karaoke timing/highlight, and pop/fade/slide ASS tags.
