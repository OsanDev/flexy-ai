# FLEXY AI v4.2.67: Caption Animation Preset Library

## What's new
- Five built-in caption looks: Cinematic Fade, Social Pop, Karaoke Glow, Minimal Slide, and Neon Reveal.
- One-click application of a preset to the selected caption.
- Save the selected caption's current style as a named custom preset.
- Custom presets are stored in the project timeline document and can be reused on its captions.
- Existing text, position, color, typography, and animation controls remain editable after applying a preset.
