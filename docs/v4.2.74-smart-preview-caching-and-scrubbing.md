# FLEXY AI v4.2.74: Smart preview caching and scrubbing

## What changed
- Proxy generation is now single-flight per media asset within a backend process. Concurrent requests for the same source wait for the first conversion and reuse its cached output instead of starting duplicate FFmpeg jobs.
- Playback Monitor seek-slider updates are coalesced to one browser animation frame, reducing redundant playhead updates during fast scrubbing.
- Original source media remains untouched and is still used for final export.

## Notes
- Proxy caching remains keyed by source file size and modification time.
- The in-process lock prevents duplicate work within one backend worker. Multi-worker deployments may still require a shared distributed lock.
- Smoothness depends on browser decode, storage and network performance.
