# FLEXY AI v4.2.72: Hardware encoder selection

## What changed
- Added FFmpeg H.264 encoder capability probing for `libx264`, NVIDIA NVENC, Intel QSV and Apple VideoToolbox.
- Added `FLEXY_VIDEO_ENCODER` configuration: `auto`, `libx264`, `h264_nvenc`, `h264_qsv`, or `h264_videotoolbox`.
- `auto` deliberately prefers `libx264` for portability. Set a hardware encoder explicitly to opt in.
- Explicit selections are rejected when the current FFmpeg build does not list that encoder.
- Render preflight now reports available encoders, the selected encoder and whether it is software or hardware.

## Configuration
Set `FLEXY_VIDEO_ENCODER=h264_nvenc` (or another supported choice) in the render server environment, then restart the backend. Keep `auto` for the portable CPU path.

## Important validation boundary
FFmpeg listing an encoder confirms that it is compiled into that FFmpeg build. It does not prove that a compatible GPU, driver, permissions or device is available. Hardware encoding therefore requires a real render test on the target server. This release does not claim measured GPU speedups and does not silently switch encoders after a hardware render failure.
