# FLEXY AI v4.2.78: Clip copy, paste, and duplicate

- Copy stores the selected video, audio, or caption clip in an editor-local clipboard.
- Paste at playhead creates a new clip of the same type at the current playhead position, preserving source range, duration, track, transition, audio mix, and caption style.
- Duplicate creates a copy immediately after the selected clip on the same track.
- Keyboard shortcuts: Ctrl/Cmd+C copy, Ctrl/Cmd+V paste at playhead, Ctrl/Cmd+D duplicate. Existing undo/redo shortcuts remain.
- New clips become selected. Operations use the existing timeline document update path and undo history.
