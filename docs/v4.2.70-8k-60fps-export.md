# FLEXY AI v4.2.70: 8K / 60 FPS Export Target

## Added
- Export panel resolution selector for 1080p, 4K UHD, and 8K UHD.
- Frame-rate selector for 24, 30, and 60 FPS.
- Export settings are included in both preflight validation and render creation.
- Backend 8K UHD preset: 7680 × 4320 at 100 Mbps target video bitrate.
- Portrait 8K output respects project orientation: 4320 × 7680.
- Existing FFmpeg x264 pipeline receives the selected dimensions and frame rate.

## Important limitations
This adds an 8K/60 FPS export target, not a guarantee of real-time or successful 8K rendering on every host. Performance and compatibility depend on FFmpeg build, CPU/GPU, memory, storage, source media, and server limits. The current renderer uses libx264 software encoding with the `veryfast` preset; hardware-accelerated encoding is not configured by this release. Benchmark on deployment hardware before advertising guaranteed 8K/60 performance.

## Validation
- Contract tests cover 8K dimensions, portrait orientation, 60 FPS acceptance, unsupported frame-rate rejection, and export UI request wiring.
