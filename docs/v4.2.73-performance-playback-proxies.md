# FLEXY AI v4.2.73: Performance playback proxies

## What changed
- Added an authenticated, project-owner-scoped proxy endpoint for video assets.
- Generates and caches a 540p, 30 FPS H.264/AAC preview proxy using FFmpeg.
- Proxy generation is opt-in from the Playback Monitor via **Performance preview**.
- The original source media and export graph are never modified; final rendering continues to use original media.
- Cache filenames include source size and modification time, so changed source media receives a fresh proxy.
- Proxy generation has a four-minute timeout and reports actionable errors.

## Notes
- Proxy generation requires FFmpeg with `libx264` and AAC support.
- The first request creates the proxy; later requests reuse the cached file.
- The browser preview can be lower resolution than the final export. This feature improves decode responsiveness, not the quality or speed of final rendering.
